OpenTTD 16.0-beta5 is now ready for testing with several bugfixes and some other changes that sneaked in:

* The default Guru X2 helicopter's life has been extended to remain available in vanilla games.
* The industry cargo chain window has been redesigned.
* Fixed a network desync after moving a station sign.
* Fixed incorrect widget sizes after an automatic font change.
* Mac OS hidden cursor handling improved.

If you find any bugs, please [report them here](https://github.com/OpenTTD/OpenTTD/issues/new/choose).
