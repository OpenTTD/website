OpenTTD 16.0-beta4 is a hotfix for a multiplayer desync in yesterday's beta3 release.

Oops.

<!-- more -->

The latest beta includes the following:

* Terraforming land in a multiplayer game no longer causes a desync that kicks you from the game

If you find any bugs, please [report them here](https://github.com/OpenTTD/OpenTTD/issues/new/choose).
